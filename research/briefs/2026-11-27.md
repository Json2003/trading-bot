## 1. Book Churn: How Fast the Order Book Is Being Rewritten — Maybe

- Published: November 18, 2026. The source supplies a date but no release time or offset, so the candidate uses `2026-11-18T23:59:59+00:00` as a conservative publication timestamp.
- Source: https://research.glassnode.com/book-churn/
- Key finding: On Binance BTCUSDT and ETHUSDT perpetuals, a causal ten-minute count of L2 price-level revisions is related to next-hour volatility, but it does not beat a causal price-range score. At z-score >=2, next-hour above-median-volatility hit rates were 63.2% and 63.4%; a 24-hour-old reading retained 58.9% and 58.4%. Churn and range scores correlated 0.84. The study is in-sample, current readings move with the price move, and API publication delay is undisclosed.
- Hypothesis implication: Treat churn as a non-directional market-state and execution-fragility measurement. Its only useful test is incremental to causal range, spread, depth and current volatility, not as a buy/sell score.
- Testing: **Maybe.** The formula and raw feed are sufficiently specified for a research candidate, so `research/candidates/btc_perp_book_churn_zscore_v1.json` is included in this branch.

Exact measurement and timing:
- Input: every bid and ask price-level tuple in Binance BTCUSDT USD-M perpetual diff-depth events; preserve exchange event time, update sequence, local receipt time, raw events and hashes. Bootstrap snapshots and resync rows never count as revisions.
- Observation: UTC ten-minute interval close. `timestamp` is that close; `available_at` is the first collector-clock instant after the interval is complete and the value is durably written. A sequence gap, reconnect or low-activity feed anomaly produces null, not zero.
- Update frequency: ten minutes. Freshness limit: 0.25 hours.
- Expected direction: higher values imply higher next-hour realized volatility and potentially worse fills; there is no expected return sign.
- Frozen research test: add one candidate to a baseline that already contains causal ten-minute range z-score, spread, depth and trailing volatility. Pre-register either (a) incremental next-open directional-model performance or (b) a stand-aside interaction with the existing directional signal. Require at least 20 independent high-churn episodes per walk-forward block, genuinely untouched chronological confirmation, and positive net performance after next-open latency, realistic fills, funding and the shared 86-bps stress charge.
- Main falsification risk: the source itself finds no advantage over price range. Feed format, reconnects, sequence handling, scheduled minute-boundary activity and regime persistence can create apparent signal. The candidate fails if it adds no untouched-forward value beyond the causal range baseline or only works after threshold/horizon selection.
