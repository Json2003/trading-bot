Set up TWS

Leave Read-Only API enabled.

  1. Sign in to Trader Workstation in the intended Paper or Live mode.
  2. In TWS API settings, enable socket clients and confirm the socket port.
  3. Set the corresponding IBKR_TWS_PAPER_ACCOUNT or IBKR_TWS_LIVE_ACCOUNT in the local launch environment, then restart the operator.
  4. Check the account here. The result verifies the expected account and reports the TWS API server version.
